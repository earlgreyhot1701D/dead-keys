# Dead Keys: accessibility and look

Target WCAG 2.2 AA. Built in, not added later.

## Rules

- Every mode has a speed slider. Practice mode (untimed) is on the main menu. Test out exists on every lesson.
- Live region announces: target cleared, life lost, wave up, milestone, lesson passed, drill source.
- Never color alone. Locked targets change shape and weight too. Heat bands carry patterns. Status carries words.
- `prefers-reduced-motion`: no shake, no flash, no scanlines, attract mode shows a still frame.
- Visible focus on every control. Every menu works by keyboard alone.
- Escape pauses into a real dialog with focus management.
- Sound is off by default.
- Attract mode: visible Pause control (WCAG 2.2.2), silent, live region quiet.
- Phone visitors and blocked storage get a one-line notice, and the game still works.

## Scoped claim (use this wording, no stronger)

Menus, settings, lesson instructions, results, progress, heat map summary, "How we count," and the share card are fully usable with a screen reader. Gameplay is visual. Practice mode with announcements is the accessible path to practice.

## Look (README Clew 2 phosphor terminal, PRD G11)

| Token | Value | Role |
|---|---|---|
| `--bg` | #0A1214 | Page ground |
| `--panel` | #0E1C1F | Panels, keycaps at rest |
| `--rule` | #3CA89C | Rules, outlines |
| `--text` | #4FE3D1 | Text; heat band "steady" |
| `--label` | #79C7C5 | Labels |
| `--muted` | #9BB0AD | Secondary text; "no data" hatch |
| `--missed` | #FF7A6B | Heat band "missed" |
| `--shaky` | #F2C14E | Heat band "shaky" |
| `--head` | Arial Narrow, Roboto Condensed, sans-serif | Headings, labels, uppercase |
| `--mono` | ui-monospace, Cascadia Mono, Consolas, monospace | Body, typed text |

Zero border radius. Double rules. Warm colors only for status. Restraint over glow: no bloom on type. Check contrast for every token pair before tokens freeze.
